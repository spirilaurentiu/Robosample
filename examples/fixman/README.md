# Fixman validation fixtures

`docs/specs/fixman-idealized-chains-validation.md` Tier 1 / Tier 2 fixtures
(Python full-stack surface, spec Sec. 3.3).

- `c4/`, `c5/`, `c11/`, `c15/` -- idealized serial bead chains (Jain 2013 Sec.
  III.A, Spiridon & Minh 2017 Sec. 3.1). Bead mass 14 amu, bond length 1.54 A,
  harmonic bonds+angles only (no nonbonded, no torsion term -- see each
  directory's `README.md`). `c4/` is the mass-corrected `examples/c4bond3`;
  `c5/c11/c15` are generated planar zigzag chains, bond angle 109 deg.
- `ace_pro_pro_nme.prmtop` / `.rst7` -- Ace-Pro-Pro-Nme (DI-proline, ff99SB;
  spec Sec. 3.2), the realistic cyclic case: two pyrrolidine rings, each
  closed via a CD-N loop-closure `DistanceConstraint`
  (`World.cpp` ~:679, `docs/specs/fixman-idealized-chains-validation.md`
  T2.0), exercising `Constraints::calcConstraintLogDet` on a real molecule.
  Provided (not generated by this change); consumed as-is by
  `tests/test_fixman_proline_realism.py`.

Tier 0 (deterministic det M identities, always-on) is C++-only and does NOT
load any file here -- it hand-builds an equivalent `RobotModel` (spec Sec.
3.3); see `tests/TestFixmanIdealizedChains.cpp`.
