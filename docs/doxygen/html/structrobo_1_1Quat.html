Detailed Description

A unit quaternion (w,x,y,z) representing the body orientation R_FM (frame M in its parent F).

Note
Constructing from a Vec4 normalizes; normalize renormalizes in place and falls back to the identity (1,0,0,0) when the norm is below 1e-12. angVelToQdot takes a parent-frame angular velocity w_FM (the leading generalized speeds of a free/quaternion joint) and returns qdot via quaternionDotFromAngVel. Represents an orientation up to the double cover q ~ -q (INV-9).
