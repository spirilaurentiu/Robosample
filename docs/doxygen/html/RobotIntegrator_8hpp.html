Detailed Description

Template definitions of the fixed-step leapfrog HMC driver (RobotEngine::verletStep / stepTo / checkReversibility) and their private position/velocity helpers.

The three public entry points are declared in RobotEngine.hpp (documented there) and defined here as templates on the force-bridge type: they touch the bridge only through bridge.evaluate(s), so the same integrator runs against the production ForceBridge and against test-only OpenMM-free bridges with no runtime indirection. The private helpers below are internal to this translation unit.

Note
Include this from the translation units that call the integrator; it is deliberately not included by RobotEngine.hpp, to avoid the RobotEngine.hpp <-> Constraints.hpp include cycle.

Drift the generalized coordinates over one step (internal helper).

Parameters
[in]mImmutable model.
[in,out]sState; writes the drifted q and renormalizes quaternion blocks.
[in]q0Pre-step coordinates.
[in]qdot0Pre-step coordinate rates.
[in]u0Pre-step generalized speeds.
[in]udot0Pre-step accelerations.
[in]qdd0Pre-step coordinate second derivatives.
[in]hStep size.
[in]nqCoordinate count.
Postcondition
Scalar DOFs use the second-order Taylor drift; quaternion DOFs advance by the exact exponential map from the midpoint angular velocity, staying unit and reversible (INV-9).
Note
The exponential-map quaternion drift deliberately diverges from a linear-Taylor-plus-renormalize update: it bypasses the quaternion second derivative and so is robust to a latent N/qddot inconsistency in the Free-joint kinematics that otherwise pumps kinetic energy. It reduces to the linear update as h -> 0, so it changes only the proposal, not the target distribution.
