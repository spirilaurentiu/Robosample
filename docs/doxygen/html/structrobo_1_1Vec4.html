Detailed Description

A 4-vector, used as raw quaternion storage (w,x,y,z) and as a qdot / qddot result before it is wrapped in a normalized Quat.

Note
Unlike Quat, Vec4 is not normalized and carries no orientation contract; it is plain storage.
