Scan the core realized state (q, u, udot, qdot, qdotdot, body origins, atom positions, body wrenches) for any non-finite value.

Parameters
[in]mModel supplying array sizes and the index->body mapping.
[in]sState scanned; read only, never modified.
[in]wherePhase label printed with the diagnostic (e.g. "calcUDot").
Returns
true when at least one scanned value is non-finite, false otherwise.
Postcondition
On the first non-finite detection of the run, prints a rich context block (phase, offending array and index, run counters, and the owning body via dumpBody) and latches firstNanDumped; on later detections prints a single-line notice. The only mutation is to the firstNanDumped process-global flag and std::cout; sampled state is untouched.
