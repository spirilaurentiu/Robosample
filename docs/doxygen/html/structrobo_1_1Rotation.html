Detailed Description

An orthonormal Mat33 representing a rigid-body rotation.

Columns are the rotated axes; operator~ returns the transpose, which for an orthonormal matrix is the inverse rotation. Constructors build a rotation from an angle about a coordinate axis, from a quaternion (fromQuaternion, which normalizes its argument), or from one/two direction axes.

Note
fromQuaternion realizes the standard R_FM map paired with quaternionDotFromAngVel (INV-9). setRotationFromTwoAxes aligns primaryAxis exactly and places planeAxis as close to planeVec as orthonormality allows (Gram-Schmidt).
