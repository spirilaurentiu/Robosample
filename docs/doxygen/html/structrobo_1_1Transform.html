Detailed Description

A rigid-body transform X_AB: frame B expressed in frame A (rotation R plus translation p).

operator*(Transform) composes frames (X_AB * X_BC == X_AC); operator*(Vec3) maps a point from B into A (R*point + p); inverse (also operator~) returns X_BA.
