Pseudo-log-determinant \( \sum \ln|\lambda_k| \) of a symmetric block, with null directions omitted.

Parameters
[in]ARow-major symmetric n x n block.
[in]nBlock dimension; 0 <= n <= 6.
Returns
The sum of ln of the absolute non-null eigenvalues. A null direction (per the shared lock) contributes 0, i.e. factor 1 to the determinant, never ln of a residue. Returns 0 for n == 0 (a Weld body: det == 1).
Precondition
A is symmetric and, for a well-posed hinge, positive definite. The magnitude is taken defensively against roundoff sign noise at the lock boundary; a genuinely negative eigenvalue is a non-PD input (a caller bug) surfaced downstream as NaN/Inf, not corrected here.
Note
This is the null-lock counterpart of invertDense: a direction the dynamics pseudo-inverse removes contributes exactly 0 here, so calcLogDetM stays consistent with the forward dynamics (INV-5, CC1).
See also
invertDense, symSqrtInv

Symmetric (Moore-Penrose) pseudo-inverse of a dof x dof hinge block \( D = H^\top P H \).

Parameters
[in]ARow-major symmetric n x n block; SPD for a well-posed hinge.
[in]nBlock dimension (1 <= n <= 6).
[out]AinvRow-major n x n pseudo-inverse.
Returns
Number of locked (null) directions: 0 for a well-conditioned A. The forward-dynamics caller uses a nonzero count to fire the CC1/CC4 fail-loud gate on any body whose lock was not anticipated.
Postcondition
Every well-conditioned direction is inverted exactly (Ainv equals the true inverse when no direction locks); every null direction inverts to 0, so Ainv is the pseudo-inverse, not a large finite regularization.
Warning
A degenerate DOF (near-zero articulated inertia, e.g. a point mass on its own torsion axis) SHALL be locked to 0, not clamped to a huge finite inverse. Zeroing that direction freezes the DOF at its initial value (a weld), the physically exact treatment of a null coordinate; a finite clamp would instead produce a ~1e14 acceleration and diverge.
See also
pseudoLogDet, symSqrtInv

Inverse symmetric square root \( S = V \, \mathrm{diag}(1/\sqrt{\lambda}) \, V^\top \) of a dof x dof block, with null directions locked to 0.

Parameters
[in]ARow-major symmetric block, conventionally DI (the invertDense pseudo-inverse of a hinge block D).
[in]nBlock dimension (1 <= n <= 6).
[out]SRow-major n x n inverse square root.
Postcondition
On every unlocked direction S is the exact inverse of symSqrt of the same block (symSqrtInv(DI) * symSqrt(DI) == I there). On any direction locked by the shared null-space test S is 0.
Note
The zero on a locked direction is the intended "no information on this gauge direction" value; it uses the same lock as invertDense and pseudoLogDet, so the mass-metric operators stay consistent with the forward dynamics (INV-5, docs/specs/singular-dof-fixman.md S3).
See also
symSqrt, invertDense

◆ kNullLockAbs

constexpr robo::Real robo::detail::kNullLockAbs = robo::Real(1e-12)
constexpr

Absolute floor of the shared null-space lock tolerance.

A direction of a hinge-inertia block is classified as null (a structural or gauge phantom, e.g. a lone single-atom Torsion body whose atom lies on its own rotation axis) when its eigenvalue magnitude is at or below the lock returned by nullLockTol, whose value never drops below this constant. Flooring the relative tolerance here keeps an all-tiny block locked rather than rescaled to nothing. This constant is the sole source of truth for null-direction classification across invertDense, pseudoLogDet, and symSqrtInv; they SHALL agree on which directions are null so their results stay mutually consistent (INV-5/INV-6, docs/specs/singular-dof-fixman.md CC1/CC4/N1).
