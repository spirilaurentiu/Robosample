Detailed Description

Development-only probes that scan realized RobotState for non-finite values and dump the offending body's coordinates.

The probes are diagnostic: they read the model and state and write to std::cout, but never mutate sampled coordinates, so including or excluding this header does not change the sampled distribution. See ROBO_DEBUG for the switch semantics and the caveat that the switch is hard-defined on here.

Macro Definition Documentation

◆ ROBO_DEBUG

#define ROBO_DEBUG   1

Master switch for the non-finite state probes.

When nonzero, the robodbg helpers and the ROBO_CHECK macro expand to active scans; when zero, ROBO_CHECK is a no-op and the probe functions are not defined.

Warning
This header hard-defines the switch to 1, so any translation unit that includes robo_debug.hpp compiles the probes in and cannot disable them from the command line (a -DROBO_DEBUG=0 would clash with this definition). The probes only read state and write diagnostics to std::cout; they never mutate sampled coordinates, so the sampled distribution is unaffected whether or not the header is included. "Compiled out" in production therefore means "the header is not included in that translation unit", not "the guard is off".
