Builds the OpenMM System, Integrator, and Context from systemTopology in the required construction order.

Parameters
[in]systemTopologySoA topology; box vectors arrive already reduced (lower-triangular). Borrowed.
[in]useMTSBuild an MTSIntegrator (else Verlet); also forces the two-tier force-group split.
[in]mtsInnerSubstepsFast-group substeps per outer step when useMTS.
[in]separateForceGroupsWhen set (and not useMTS), give each force its own group.
[in,out]alchemyFactoryRead for Region-A state by the two createAlchemy*Force builders; its setAlchemyForce records which force the vacuum/implicit path built (nullptr under explicit-solvent decoupling).
Returns
The built objects; check .success.
Exceptions
std::runtime_erroron periodic setup without 9 box vectors, a cutoff exceeding half the smallest box width, a massless non-virtual-site particle, NCMC alchemy combined with NBFIX, or more than 32 separate force groups. Context construction failure is reported via .success == false, not thrown.
Postcondition
Forces are placed per the force-group policy: MTS -> slow group 0 / fast group 1; else separateForceGroups -> one group per force; else all in group 0.
