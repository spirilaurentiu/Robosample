Coupling parameter lambda for NCMC protocol substep step: a palindromic tent 1 -> 0 -> 1 with an optional flat lambda = 0 hold.

Parameters
[in]stepProtocol substep index; conventionally in [0, ncmcSteps).
[in]ncmcStepsTotal number of switching substeps.
[in]holdFractionFraction of ncmcSteps spent in a flat lambda = 0 hold centered on the trough (the uncaged stride); 0 for a plain triangle.
Returns
lambda in [0, 1].
Postcondition
protocolLambda(0, N, .) == protocolLambda(N-1, N, .) == 1: both endpoints are fully coupled.
Palindromic: protocolLambda(s, N, .) == protocolLambda(N-1-s, N, .). The value decreases monotonically to the trough (lambda == 0 at the center) and increases monotonically back to 1; it is symmetric, not globally monotone. This palindrome is what makes accept-on-endpoint the exact Metropolis test for the reversible NCMC map.
Note
Defined for any integer step: indices outside [0, N) clamp into [0, 1]. ncmcSteps <= 1 returns 1 (a single fully-coupled substep); a holdFraction wide enough to consume the whole protocol returns 0 away from the pinned endpoints.
