Advance one Gibbs block: load a configuration into a World, take one sampling move, and read the post-move configuration back out.

The single sweep primitive shared by all replica-exchange drivers. One call is exactly setAtomsLocationsInGround(coords) -> generateSample() -> getAtomsLocationsInGround() -> coords. A driver builds a Gibbs sweep by calling this once per World in schedule order on the same coords buffer.

Parameters
[in,out]wThe World for this Gibbs block. Borrowed; the move reads coords into it, samples, and leaves the World's transient sampler state overwritten. The World retains no per-replica state that survives this call (INV-3): the returned coords is the only thing carried to the next block.
[in,out]coordsPer-atom Ground-frame Cartesian coordinates (nm, engine/OpenMM atom order), the sole inter-world currency (INV-3). On entry the configuration to sample from; on return the post-move configuration (unchanged on a rejected move). Must hold at least numAtoms elements.
[in]numAtomsAtom count to copy back out of the World. Must equal the World's atom count and coords.size().
Returns
true if generateSample() accepted the move, false if rejected. The accept flag is telemetry only; coords already reflects the accepted-or-restored configuration either way.
