4// RobotModel — the immutable, precomputed, per-World graph. Built ONCE in
5// World::build() from the SoA SystemTopology + this world's per-bond
6// mobilities. Never rebuilt on a coordinate transfer (this is what kills the
7// per-transfer realizeTopology() cost in the current code).
8//
9// This is a faithful SoA port of what World currently precomputes across
10// decomposeRigidUnits / buildFrameGraph / modelOneCompound / modelTopologies,
11// with the joint frames and mass properties stored as CONSTANTS rather than
12// Simbody topology-stage defaults.
13//
14// SoA, no vtables. Joint identity is an enum per body, branched in the engine
15// (replacing Simbody's RigidBodyNode virtual dispatch).
16//
17// Tables here are built once and never resized; std::vector is fine. They can

35enum class JointType : std::uint8_t {
36 Rigid = 0, // 0 dof
37 Torsion, // 1 dof rotation about the bond axis (the canonical dihedral)
38 Slider, // 1 dof translation along the bond axis
39 Cylinder, // 2 dof rotation + translation about/along the bond axis
40 BendStretch, // 2 dof rotation perpendicular to the bond + translation along it

42 Ball, // 3 dof rotation, q = 4 (quaternion) by default
43 SphericalCoords, // 3 dof BAT (azimuth, zenith, radius)
44 FreeLine, // 5 dof 2 rotations (no spin about own line) + 3 translations, q = 7

49// INDEX / ORDER CONVENTIONS (must match python/robosample/molecule_prototype.py
50// and z_matrix.py exactly -- see MIGRATION_PLAN_v2_corrections.md Part B 5/6):
51// * Atoms arrive in BFS/compound order from the root (compound 0 == root).
52// The array position IS the atom index; Molmodel cAIx is retired.
53// * Bonds are oriented PARENT->CHILD (root-ward first): bondsI=parent,
54// bondsJ=child. Ring-closing bonds are flagged (transmitted explicitly)
55// and are NEVER tree edges (skipped in decomposeRigidUnits/buildFrameGraph).
56// * Angles oriented i->k (j center); proper torsions oriented i->l; all
57// root-ward-first, matching Python.
58// * Z-MATRIX uses the standard BAT convention and is the OPPOSITE direction:
59// zI = atom PLACED; zJ/zK/zL = back-references TOWARD root
60// (parent / grandparent / great-grandparent). BAT = dist(zI,zJ),
61// angle(zI,zJ,zK), dihedral(zI,zJ,zK,zL). -1 sentinels in leading rows.
62// * Frame-graph ancestry names: self / parent / grandParent (root-ward).
63// (refChild only exists if the legacy A1 orientation switch is kept.)
64// ----------------------------------------------------------------------------

133 // ---- kinetic-metric preconditioning (fictitious mass; SAMPLING only) ----
134 // Per-body scale applied to the body spatial inertia Mk_G in the KINETIC
135 // metric ONLY: the momentum draw (sqrt(M^-1)), the kinetic energy
136 // (1/2 u^T M u), and the Fixman log-det (ln det M). Default 1.0 == physical.
137 // MUST be a run-constant (never a function of q). Does NOT enter V.
138 //
139 // Why this is bias-free: Mk_G is the single source for P/D (hence both the
140 // sqrt(M^-1) draw and ln det M) and for calcKineticEnergy, so scaling it by a
141 // constant s_b shifts ln det M by the constant sum_b dof_b * ln s_b, which
142 // cancels in dH; and the marginalised det(M)^{1/2} is cancelled exactly by
143 // the Fixman exp(-beta F) for the SAME (scaled) M. Net effect: the sampled
144 // configurational distribution is unchanged; only the proposal dynamics are
145 // rescaled, raising the stable dt ~sqrt(s_b) for the scaled body. Used to
146 // tame stiff explicit-solvent libration. See World::setMassScaleByJoint /
147 // setBodyMassScale. May be left empty (treated as all-1.0).

238 [[nodiscard]] static constexpr int jointNQ(JointType jt) {
239 // Quaternion bodies inflate the orientation block from 3 (rotational u)
240 // to 4 (unit quaternion q): Ball (4), FreeLine (4 + 3 trans = 7), Free
241 // (4 + 3 trans = 7). All others have nq == nu.
