Detailed Description

A spatial 6-vector split into an angular and a linear Vec3.

Note
operator[] indexes [0] == angular, [1] == linear (SimTK convention). Used for spatial velocities, accelerations, and wrenches (angular = moment/torque, linear = force). The free dot sums both halves.
