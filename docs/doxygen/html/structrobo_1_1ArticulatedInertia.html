Detailed Description

A symmetric spatial 6x6 inertia in three 3x3 blocks P = [[angAng, angLin],[~angLin, linLin]].

Acting on a spatial vector: out.angular = angAng*w + angLin*v, out.linear = ~angLin*w + linLin*v. The three-block constructor takes (massBlock=linLin, momentBlock=angLin, inertiaBlock=angAng), matching the engine's call order. shift rigidly translates the inertia to a point offset away (Phi(offset) P ~Phi(offset)); the articulated-body recursion uses operator+= / operator- to assemble and remove child contributions.
