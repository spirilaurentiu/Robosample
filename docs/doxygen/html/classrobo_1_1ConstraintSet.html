) const -> Real

Loop-closure contribution to the Fixman potential, ln det(G M^-1 G^T).

Parameters
[in]modelImmutable model.
[in,out]stateRealized state; used as scratch by multiplyByMInv, not left with observable coordinate changes.
Returns
ln det(G M^-1 G^T) up to an additive constant that depends only on the (fixed) constraint count and cancels in any Metropolis dH. Returns exactly 0 when there are no loop-closure constraints (an acyclic molecule, whose flexible-coordinate determinant is the articulated-body tree determinant from RobotEngine::calcLogDetM alone).
Precondition
realizeArticulatedBodyInertias() is current for state (needed by multiplyByMInv).
Note
G is assembled by the same assembleConstraintRow helper as SHAKE and RATTLE (INV-6), so this correction matches the projected subspace exactly. It supplies the ring term |M_flex| = |M_tree| / |G M^-1 G^T| that the tree determinant omits for cyclic systems (Spiridon & Minh 2017, JCTC 13:4649, Eqs. 2-3).

SHAKE: Newton-iterate the generalized coordinates until every constraint C(q) = |rAB|^2 - d0^2 is satisfied to tolerance.

Template Parameters
RefreshFnCallable void() that rebuilds atom positions and the kinematic Jacobian from the current q; invoked once per iteration because C is nonlinear.
Parameters
[in]modelImmutable model.
[in,out]stateCoordinates q are projected in place.
[in]refreshKinematicsRe-realizes positions/H from q.
[in]toleranceConvergence bound on the worst |C| (default 1e-10).
[in]maxIterIteration cap (default 50).
Returns
The number of Newton iterations taken (0 when there are no constraints; maxIter if it did not converge).
Postcondition
On convergence every constrained bond length equals its rest length to tolerance.
