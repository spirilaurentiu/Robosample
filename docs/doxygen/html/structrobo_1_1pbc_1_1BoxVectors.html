Detailed Description

Three reduced (lower-triangular) periodic-box lattice vectors, stored flat as [a.x a.y a.z b.x b.y b.z c.x c.y c.z] in nm.

Note
Reduced form: a=(ax,0,0), b=(bx,by,0), c=(cx,cy,cz), positive diagonal, |bx|<=ax/2, |cx|<=ax/2, |cy|<=by/2. Same layout and order as SystemTopology::boxVectors and OpenMM's reduction.
