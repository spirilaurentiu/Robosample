Detailed Description

One per-frame, per-body reaction-force snapshot row (docs/specs/reaction-force-monitoring.md Sec.1/3/4).

force and torque are the spatial force about the body origin Bo, in Ground, and are the SUM of whichever term(s) World::enableReactionReporter enabled: the OpenMM net applied force (bodyForceG) and/or the static (u=0) mobilizer reaction (RobotEngine::calcMobilizerReactionForces). Both terms are spatial forces about the SAME point (Bo, in Ground), so summing them is a valid spatial-force addition, not an apples-to-oranges combination; which term(s) are included is a per-reporter-world choice, not encoded in the row itself (Sec.1.2).

Note
Values are RAW (native units, no normalization). Normalization, if wanted, is a render-only transform applied downstream of this CSV, in vmd/arrows.tcl, never here.
