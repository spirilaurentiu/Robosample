Detailed Description

Result of a Route-B normal-mode analysis over one configuration.

A plain value bundle returned by computeRouteBNMA. eigval holds the mode frequencies \( \omega_k^2 \) in ascending order under the mass-weighted u-metric; modeU[k] is the k-th mode in generalized-speed (u) space ( \( v_k = N y_k \)); softMode indexes the chosen softest non-rigid mode; nNearZero counts the rigid/external/noise modes below the zero tolerance (about 6 per Free-rooted molecule); uScaleFactors is modeU[softMode] renormalized to unit length, the direction the NMA momentum bias consumes.
