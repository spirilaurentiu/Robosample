Detailed Description

Owning result of OpenMMSystemBuilder::build; the caller moves these into its own members.

Note
Partial-write-on-failure: system, integrator, hasVirtualSites, numAtoms, and forceGroupLabels are populated even when success is false, because they are fully built before the Context construction that may throw. context and openMMVersion are valid only when success is true.
