Detailed Description

Route-B normal-mode analysis: the mass-weighted internal-coordinate Hessian and its softest non-rigid mode, used to bias HMC momenta.

robo::computeRouteBNMA builds the generalized stiffness \( K_{ab} = \partial^2 V / \partial s_a \partial s_b \) by central differencing the generalized force, mass-weights it into \( \tilde H = N^\top K N \) with \( N = \sqrt{M^{-1}} \) (the same articulated-body factor RobotEngine::multiplyBySqrtMInv applies, so \( N^\top M N = I \)), diagonalizes, and returns the softest non-trivial mode as a unit-norm generalized-speed direction. It reads the model and state and restores the state to the input configuration; it does not touch the sampler, set momenta, or run acceptance.
