Detailed Description

One aligned, contiguous memory slab handed out as fixed byte-offset handles: a two-phase bump allocator for struct-of-arrays layouts.

Usage protocol (two phases)
Reserve every sub-array with reserve() (records offsets, allocates nothing), then commit() once (a single aligned allocation), then obtain typed pointers with ptr(). reserve() after commit() throws; commit() is idempotent.
Ownership and lifetime
The arena owns its slab and frees it on destruction or move-assignment. Every pointer from ptr() is borrowed: it stays valid only while this arena is alive and un-reassigned. Move transfers the slab and nulls the source; move-assigning a new arena frees the previous slab, invalidating all pointers previously obtained from the destination. Non-copyable.
Note
Every sub-array begins on a kAlign (64-byte) boundary, so aligned SIMD loads over any reserved array are legal.
