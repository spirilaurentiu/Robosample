Detailed Description

The pure lambda(step) coupling schedule for the per-molecule NCMC switch (Nilmeier, Crooks, Minh & Chodera 2011).

World::protocolLambda delegates to robo::ncmc::protocolLambda, so production and tests exercise one definition. The coupling parameter follows the convention lambda == 1 fully coupled, lambda == 0 fully decoupled; the alchemy force this schedule drives SHALL use the same convention, so both NCMC endpoints sit in the physical (fully-coupled) ensemble the work accounting assumes.
