The log-determinant of the mass matrix, ln|M| = sum_b ln det(D_b), the O(n) articulated-body determinant.

Parameters
[in]mImmutable model.
[in]sRealized state.
Returns
ln|M|, the Fixman kinetic term.
Precondition

Note
Matrix-free: only each per-body hinge inertia D_b = H^T P H (dof <= 6) is formed; its pseudo-log-determinant (robo::detail::pseudoLogDet) omits null-locked directions, so ln|M| stays consistent with the forward-dynamics pseudo-inverse (INV-5).

Reaction forces the inboard mobilizer transmits to each body, expressed in Ground.

Parameters
[in]mImmutable model.
[in]sFully realized state.
[out]reactionAtBoInGReaction at each body origin Bo in Ground, length numBodies (slot 0 for Ground is left zero); pass nullptr to skip.
[out]reactionAtMInGThe same reaction shifted to each outboard mobilizer frame origin Mo in Ground ([t;f] at Bo -> [t - p_BoMo_G x f; f] at Mo); pass nullptr to skip.
Precondition
realizePosition, realizeVelocity, realizeArticulatedBodyInertias, and calcUDot are all current. At least one output pointer is non-null.
Note
Exact rigid Newton-Euler inward transmission (no articulated inertia). Following Simbody, applied mobility (generalized joint) forces are NOT subtracted, so they are included in the reported reaction; only bodyForceG counts as the external force.

Advance the state by exactly one fixed-step leapfrog HMC step in generalized coordinates.

Template Parameters
BridgeForce provider; the integrator touches it only through bridge.evaluate(s), which fills bodyForceG / mobilityForce and reports whether the forces are finite. Any type meeting that interface may instantiate this (the production ForceBridge and the test AnalyticForceBridge both do); OpenMM stays out of the header.
Parameters
[in]mImmutable model.
[in,out]sState advanced by one step h.
[in,out]bridgeForce provider (see Bridge).
[in]csetLoop-closure constraints; the SHAKE position projection and the trapezoid velocity correction use the same G as the Fixman log-det (INV-6).
[in]hStep size.
[out]correctorConvergedOptional; if non-null, receives whether the implicit-trapezoid velocity corrector reached its fixed point. The step is taken unconditionally either way; a caller that needs F-reversibility (e.g. inner NCMC) SHALL treat a false readback as a reject.
Returns
true on success; false if a non-finite force or coordinate appeared during the step, in which case the pre-step q / u are restored so the caller sees a finite, unmodified state to reject from.
Postcondition
One reversible leapfrog step: position drift (quaternion DOF via the exact exp-map, INV-9) with quaternion renormalization, SHAKE position projection (INV-6), then the implicit-trapezoid velocity correction. The realization stages run in the canonical order (INV-4). A behavior-preserving reorder of the internal helper calls does not change this contract.
